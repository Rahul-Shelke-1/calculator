# Installation

You can install the calculator package directly from GitHub using `pip`.

## Standard Installation

Run the following command in your terminal or virtual environment:

```bash
pip install git+https://github.com/Rahul-Shelke-1/calculator.git
```

## Developer Installation

If you intend to contribute to development or edit the source code locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Rahul-Shelke-1/calculator.git
   cd calculator
   ```

2. Install dependencies (e.g., using `uv` or `pip`):
   ```bash
   pip install -r requirements.txt
   ```
